# Pi Chat Exchange 0.3.1 候选

状态：候选，尚未发布。npm包、MCP服务器和Desktop插件统一为0.3.1。发布仍须绑定经审查的确切提交、新鲜Hosted检查、当前Tunnel兼容性与实际制品安装证据。

本候选将本地daily整合内容纳入可重建源码：会话引导与恢复、限定作用域的后台启动许可、Hook管理、原生任务接入、桌面目标捕获及结构化归属反馈。原生反馈按实际outgoing key和probe关联，在单次原生接收后记录终结结果；不从标题、前台或任务名推断身份。

仓库还包含可选的本地Python桌面Hook工具；它们不进入npm tarball，安装包也不会自动启用。共享observer对缺失/非字符串草稿明确拒绝，选择器诊断记录实际控件数量而不保存正文。CHECK_ONLY适配器保持全文精确比对、明确enabled检查、单次输入/点击和UNKNOWN历史不变。本候选保留原有前台门控；已证实的后台语义草稿写入不证明后台提交能力。

## 验证范围

- 固定生产安装曾完成真实UNVERIFIED、MATCH查询及Pi终结反馈往返；它们是历史证据，不认证新构建包。
- WRONG_CONVERSATION查询判断通过，但结构化反馈被OpenAI工具安全检查阻断，原因未知；完整路径仍未验收，不绕过或重试。
- 提交后UI证据不足时，初始自动提交保持UNKNOWN。后续客户端和终结反馈不改写初始记录；不提供Return/IME替代提交或自动重试。
- CHECK_ONLY通知fallback保持关闭，业务DELIVER_REPLY保持explicit-only。安装包不扩大权限、不登记owner、不改Tunnel配置或启动另一Host。
- 最新Tunnel0.0.20仍需与0.3.1 runtime匹配的生命周期、真实Cloud及新鲜Hosted离线验证。证据不足时保持BLOCKED；旧0.3.0/Tunnel0.0.19结果不认证此候选。

Registry、公开SHA/Tag/Workflow、tarball身份及实际安装运行分别核验通过前，不宣称Released或Post-release Accepted。
