# CE 0.3.4 候选版

此候选版为 TaskOwner 查询增加明确选择的 CE Store 证明。在核对私有 Store 范围、精确消息投影和权威 Owner 登记后，允许已登记的业务 Owner 标签不同于选中的 Pi endpoint。旧 sidecar 保留原有 endpoint 等值行为；实时 lease、注册、recipient 和 policy 准入仍然适用。

Python 业务登记 Guard 在读取正文前，也会在 Store 锁内检查当前 Owner。即使冲突已写入而投影更新中断，该读取也会被拒绝。

成功查询反映打开 Owner 记录时的状态，不能撤销已返回的结果、为后续操作提供 fencing、防止受信任私有 Store 被替换或回滚，也不能证明桌面对话身份。已安装的 Python Guard 需要通过其受支持的生命周期单独更新，npm 包不代替这一步。

这仍是候选版。本地测试不证明托管 CI、同源 Cloud 资格、正式发布或生产采用。
