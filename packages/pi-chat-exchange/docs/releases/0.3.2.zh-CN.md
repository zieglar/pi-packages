# Pi Chat Exchange 0.3.2 候选

状态：本地候选，尚未发布。npm 当前公开版本仍为 0.3.1。本补丁从公开 0.3.1 源码准备，不包含后续 daily 的 runtime-binding、named-group 或会话切换改动。

原生任务接入会在展示 Hook 替换大型工具输出前，为当前调用保留其拥有的协议结果。原生消费者使用精确结果，面向模型的输出仍经过展示 Hook。注册 SDK 工具和 Hook 照常执行；元数据、UTF-8 长度、摘要、Session 与 endpoint 校验不变，也不会将错误或拒绝恢复为成功。保留结果按父调用、嵌套调用、工具与消息关联，只能消费一次，并在调用结束时清理。

制品通过原有扩展文件清单包含 `pi-extension/native-read-protocol.ts`。没有新增依赖、安装 Hook、原生二进制、自动激活或配置迁移。TaskOwner 登记、选择器权限、工具权限与禁止重放账本保持不变。
