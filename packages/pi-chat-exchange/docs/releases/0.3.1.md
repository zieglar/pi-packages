# Pi Chat Exchange 0.3.1 candidate

Status: candidate, not released. The npm package, MCP server and Desktop plugin identify version0.3.1. Publication remains gated on an exact reviewed commit, fresh hosted checks, current tunnel compatibility and actual artifact installation.

This release candidate brings the local daily integration into a reproducible source tree: session onboarding/recovery, scoped background startup permission, hook management, native task intake, desktop target capture and structured ownership feedback. Native feedback correlates the actual outgoing key/probe and records a terminal result after a single native receive. No identity is inferred from titles, focus or task names.

The repository also carries optional local Python desktop Hook tools. They are author/operator tooling and are not included in the npm tarball or auto-enabled by installing the package. The shared observer now refuses missing/non-string composer values rather than treating them as empty. Diagnostic counts describe actual selected controls and never include draft text. The CHECK_ONLY adapter preserves full input equality, explicit enabled checks, once-only input/click attempts and immutable UNKNOWN history. Its existing foreground requirement remains in this candidate; separately demonstrated background semantic draft writes do not certify background submission.

Publication still requires its own fresh same-run qualification. No namespaced Cloud identity, forced-kill recovery, remote slow-Hook/timeout or desktop submission qualification is claimed.
