# Pi Chat Exchange 0.3.2 candidate

Status: local candidate, not released. The published npm version remains 0.3.1. This patch is prepared from the public 0.3.1 source; it does not include later daily runtime-binding, named-group or session-switch changes.

Native task intake now retains its owned protocol results for the current invocation before presentation Hooks can replace large tool output. The native consumer uses those exact results while the model-facing output still passes through presentation Hooks. Registered SDK tools and Hooks still execute. Metadata, UTF-8 length, digest, Session and endpoint checks remain unchanged; an error/refusal cannot be restored to success. Captures are correlated to the parent call, nested call, tool and message, consumed once and cleared when the invocation ends.

The tarball includes `pi-extension/native-read-protocol.ts` through the existing extension file inventory. No new dependency, install hook, native binary, automatic activation or configuration migration is introduced. TaskOwner registration, selector authority, permissions and the no-replay ledger are unchanged.

That record covers the original large-message failure path on the adopted daily package; it does not certify this versioned archive or every CE integration path.

Local preparation does not authorize commit, push, PR, merge, tag, publication or GitHub Release.

Do not describe 0.3.2 as released or post-release accepted until the registry, source SHA, hosted workflow, tag/Release, archive identity and installed-artifact evidence have passed their respective gates.
