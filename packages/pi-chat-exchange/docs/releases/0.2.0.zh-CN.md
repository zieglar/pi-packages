## 安装路径

`@zieglar/pi-chat-exchange@0.2.0` 已发布 npm。使用可信 registry 时，原生 managed npm 路径为：

```sh
"$CE_APPROVED_NODE" "$CE_PI_CLI" install npm:@zieglar/pi-chat-exchange@0.2.0
"$CE_APPROVED_NODE" "$CE_PI_CLI" list
```

使用获批的绝对 Node、Pi 1.3.0 CLI 路径，使用该 Node 提供的 npm、私有配置/cache 和 ignore-scripts。Pi 禁止自动安装 peer，独立 Host 提供 Pi peer。0.2.0 安装命令证据来自自有 loopback registry，并非公共 npm；该历史测试本身不认证公共 registry 安装。依赖前始终确认精确版本可解析。

[独立安装](../independent-install.zh-CN.md) 说明独立预构建 tarball 资产 fallback 及强制安全卸载/升级/回滚流程。GitHub 资产先下载、哈希，再物理 prefix 安装，不作为 Pi URL 传入；monorepo 源码加载属开发路径，不是 managed npm。不要同时加载两份。

## 生产方记录与产物完整性

作者使用冻结的 pnpm 12.9.1 依赖、ignore-scripts 和获批 Node。在包内运行 `pnpm run package:pi-extension`：build → 验证磁盘闭包 → 验证 native pack 清单 → 无 hook 打包。保留精确 `.tgz`、SHA256/SRI、清单、固定提交、lockfile 哈希、工具版本、argv/私有环境及测试证据。不得在消费端重建，也不得用旧归档替换已测试产物。

若 0.2.0 经 GitHub Release 资产分发，必须是精确已测 `zieglar-pi-chat-exchange-0.2.0.tgz`，加由 `shasum -a 256 zieglar-pi-chat-exchange-0.2.0.tgz > SHA256SUMS` 生成的 `SHA256SUMS`。消费方下载两者并在安装前运行 `shasum -a 256 -c SHA256SUMS`。验证与上传之间不重建归档。

**完整性声明限制。** 框架计算产物 SRI/SHA256 元数据，经自有 loopback registry 提供精确字节，逐文件比较已安装 payload 与已测归档。证据为元数据加已安装 payload 字节一致性。没有损坏元数据/损坏 payload 的**完整性拒绝负向测试**，因此不声称消费端 npm 会拒绝篡改产物。

第三方 LICENSE 证据门禁已闭合：逐版本证据保留于作者私有证据库，并在仅仓库、不随 tarball 分发的 `docs/license-audit.md` 汇总。分发 pin 改变时，须针对新 pin 重新确认。云传输验证为独立且尚未决定的范围，0.2.0 不作云声明。

## 隔离作者回归（显式 opt-in，仅仓库）

本发布说明随 tarball 分发，但本节指令**仅限仓库，消费端不可执行**：描述的作者框架脚本只存在 monorepo，从不随包分发。

在全新私有归档 stage、物理安装冻结依赖后，将 `CE_DISTRIBUTION_ARCHIVE` 设为新验证的 0.2.0 `.tgz`，`CE_DISTRIBUTION_NPM_CLI` 设为获批 Node 的 `npm-cli.js`。运行 `pnpm run test:distribution-npm` 测实际原生 Pi install/remove/reinstall，`pnpm run test:distribution-host` 测独立物理 tarball 路径。两者要求精确 Node 24.21.0 和 macOS sandbox-exec，缺前提时明确失败。保留私有证据，使用既有 guardian 管理 Host/native npm 后代。不得针对真实 profile 或凭证运行。四个既有重型默认排除项不变。

这些测试使用真实 Pi/PTY 和真实 managed package 安装，但 registry 自有 loopback，配置/Store/key 均合成。包自身字节来自 loopback；仅普通第三方依赖在安装阶段从 npmjs 下载。运行时离线且被 Seatbelt 禁网。不执行真实 Tunnel 客户端。打包模拟器的真实进程 owned stop，以及后台管理器 external-owner/UNKNOWN/refusal 情形属独立针对性测试，不证明云传输，也不自动证明无其他用户。
