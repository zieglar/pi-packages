# CE 0.3.4 candidate

This candidate adds an explicitly selected CE Store proof for TaskOwner lookups. It allows the registered business owner label to differ from the selected Pi endpoint while checking the private Store scope, exact message projection and authoritative owner record. Existing sidecars retain their previous endpoint-equality behavior. Live lease, registration, recipient and policy admission remain required.

The Python business registry guard also checks the current owner under its Store lock before reading a payload. A conflict recorded before projection updates therefore denies that read, including after an interrupted update.

A successful lookup describes the owner record at the time it was opened. It does not revoke a result already returned, fence later actions, protect against replacement or rollback of the trusted private Store, or establish a desktop conversation identity. An installed Python Guard must be updated through its supported lifecycle separately from the npm package.

This is a candidate. Local tests do not establish hosted CI, matching-source Cloud qualification, publication or production adoption.
