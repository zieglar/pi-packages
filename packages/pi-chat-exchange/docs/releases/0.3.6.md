# CE 0.3.6 candidate

This candidate consolidates the ordinary Pi command surface under `/ce`. It adds status, setup, Session bind/unbind/list, native inbound status/enable/disable and advanced transport/native/hooks/bindings/maintenance routing while retaining the older commands as hidden compatibility shims.

Native inbound remains disabled until the operator explicitly supplies one sender Endpoint in the Pi TUI and confirms the exact current Session, Endpoint, Exchange and audit high-water boundary. Activation rechecks those facts after confirmation and atomically writes a private per-Session policy. Disable changes only that policy; it does not delete history, change Owner, acknowledge messages, or stop Tunnel/MCP.

The release does not change the message protocol, Store Schema, ownership authority or shared Tunnel lifecycle. Status reports measured evidence when the supported observer can provide it and otherwise reports `UNKNOWN`.

Verification used Node 24.21.0 and Pi 1.3.0 on macOS arm64. The final canonical default suite passed 3741 tests with 18 explicitly skipped; the inbound-focused suite passed 93 tests, and contract, typecheck, build, release-gate and plugin-package checks passed. These results do not establish another platform, hosted CI, Registry publication, successful production adoption or business-task completion. The trusted publishing workflow must independently rebuild, verify the exact public commit, run fresh Tunnel 0.0.20 compatibility evidence and refuse an existing version before one publication attempt.
