# Pi Chat Exchange 0.3.3 candidate

This release unifies the accepted daily capabilities in the formal TypeScript source and package build. It adds Session Switch observation, current and explicit Runtime Binding, operator-owned Named Groups, the Pi `ce-bind` command, a rebuilt TaskOwner guard, and the default-off Source Metadata Probe. It retains the published 0.3.2 native-read behavior and existing messaging, ACK, Hooks, Native and Tunnel contracts.

TaskOwner reads are scoped to the exact Exchange, sender, recipient and message ID. The private registry is bounded and fail-closed, and every query rechecks the active lease, bound port, current live registration and policy admission. Endpoint or Runtime selection, transport health, message persistence and ACKs do not grant task ownership.

The Source Metadata Probe activates only when a trusted launch value equals the exact launch-document digest. It samples one successful `ping`, records only presence/type and a process-local keyed digest for a bounded string, and remains disabled otherwise.

Publication requires a clean committed source, matching-source lifecycle and manual Cloud evidence for the current official Tunnel Client, a fresh same-run hosted compatibility result, an exact `publish_sha`, and npm artifact/provenance verification. Released and post-release accepted are separate states.
