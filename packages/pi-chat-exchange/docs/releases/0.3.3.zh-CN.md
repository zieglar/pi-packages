# Pi Chat Exchange 0.3.3 候选

本版本将已验收的 daily 能力统一纳入正式 TypeScript 源码和制品构建：Session Switch、当前/显式 Runtime Binding、操作者管理的 Named Groups、Pi `ce-bind`、重建的 TaskOwner Guard，以及默认关闭的 Source Metadata Probe。已发布 0.3.2 的 native-read 行为与既有消息、ACK、Hooks、Native、Tunnel 契约保持不变。

TaskOwner 查询严格绑定精确 Exchange、发送方、接收方和 message ID。私有 registry 采用有界、失败关闭读取；每次查询都会重新检查 ACTIVE lease、bound port、当前实时注册及 policy admission。Endpoint/Runtime 选择、transport health、消息持久化与 ACK 均不授予任务归属权。

Source Metadata Probe 仅在可信启动值与精确 launch document digest 相等时启用，只采样一次成功 `ping`，仅记录存在性、类型及对有界字符串生成的进程内 keyed digest；其他情况保持关闭。

发布前必须具备 clean committed source、匹配当前官方 Tunnel Client 和精确源码的 lifecycle/manual Cloud 证据、同一发布 run 的新鲜 hosted compatibility 结果、精确 `publish_sha`，以及 npm 制品/provenance 核验。Released 与 Post-release Accepted 分开判定。
