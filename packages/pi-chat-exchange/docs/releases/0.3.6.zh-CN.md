# CE 0.3.6 候选版

本候选版将 Pi 的普通用户命令统一到 `/ce`。它提供状态、设置、Session bind/unbind/list、native inbound status/enable/disable 及高级 transport/native/hooks/bindings/maintenance 路由；旧命令仅作为隐藏的兼容入口保留。

Native inbound 默认保持关闭。操作者必须在 Pi TUI 中显式输入一个 sender Endpoint，并确认当前 Session、Endpoint、Exchange 及 audit 高水位边界。激活会在确认后重新校验这些事实，然后原子写入当前 Session 的私有策略。停用只改变该策略，不删除历史、不改变 Owner、不 ACK 消息，也不停止 Tunnel/MCP。

本版本不改变消息协议、Store Schema、归属权限或共享 Tunnel 生命周期。支持的观测器能提供证据时显示实测状态，否则显示 `UNKNOWN`。

验证环境为 macOS arm64、Node 24.21.0 和 Pi 1.3.0。最终 canonical 默认套件 3741 项通过、18 项显式跳过；inbound 针对性套件 93 项全部通过，contract、typecheck、build、发布门及插件打包检查也通过。这些结果不代表其他平台、托管 CI、Registry 发布、生产采用或业务任务完成已验证。Trusted Publishing 工作流仍必须独立重建并验证精确的公开提交，生成新的 Tunnel 0.0.20 兼容证据，在确认版本不存在后仅尝试发布一次。
